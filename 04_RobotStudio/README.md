# RobotStudio

En esta carpeta se almacenarán los archivos relacionados con la simulación realizada en RobotStudio.

Aquí se incluirán:

* **Estación de RobotStudio:** Archivo de la estación virtual (`.rspag`).
* **Archivos de la simulación:** Configuración del controlador y celda.
* **Herramienta importada:** Modelo CAD importado y configurado como `tooldata`.
* **WorkObjects utilizados:** Definición de `wobjdata` en los cuadrantes requeridos.
* **Trayectorias programadas:** Rutinas `Path` de movimiento.
* **Otros archivos necesarios para la simulación.**
