# Código RAPID

En esta carpeta se almacenará el código completo utilizado durante el desarrollo del laboratorio.

Aquí se incluirán los módulos y procedimientos utilizados para:

* **Rutina de decoración:** Trazado de los nombres y la figura de Pac-Man.
* **Control de la banda transportadora:** Rutinas de avance, retroceso y paro (`FWD_Conveyor`, `BWD_Conveyor`).
* **Ciclo automático:** Secuencia completa iniciada por `DI_01`.
* **Pose de mantenimiento:** Posición segura activada por `DI_02`.
* **Rutina Farmear Aura:** Secuencia creativa activada por `DI_03`.
* **Control de las entradas y salidas digitales:** Gestión de señales `DI` y `DO`.
* **Retorno del robot a HOME:** Posición de inicio y fin de ciclo.
